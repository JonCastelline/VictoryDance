# VictoryDance

A lightweight Windower 4 addon for Final Fantasy XI that automatically performs an emote (default `/dance1 motion`) as a flourish whenever a monster you are fighting is defeated.

## Commands

- `//vd on` - Enable automatic flourish on kill
- `//vd off` - Disable automatic flourish
- `//vd test` - Preview the victory dance immediately
